I'm a software engineer from Maranhão, Brazil, focused on turning product ideas into maintainable software. My work spans TypeScript and Python applications, web and React Native experiences, backend APIs, real-time communication, and experiments with AI agents and the Model Context Protocol.

- Building web products with **TypeScript**, **React/Next.js**, and **Angular**

- Developing cross-platform mobile applications with **React Native** and **Expo**
- Exploring **AI agents**, **LLM streaming**, and **MCP-based tool integrations**
- Working with relational and document databases, API design, testing, and containerized environments
- Open to collaboration and professional opportunities
